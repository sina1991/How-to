# راهنمای سفر، Backup و بازیابی

## پیش از سفر
- روی موبایل شخصی Termius را با همان کلید اصلی تست کنید.
- نسخه رمزگذاری‌شده هر دو فایل 30na_windows و 30na_windows.pub را در محل امن قابل دسترسی نگه دارید؛ مثلاً USB رمزگذاری‌شده یا Password Manager معتبر با امکان نگهداری فایل.
- Passphrase را امن و جداگانه نگه دارید. MFA حساب‌ها و روش بازیابی آن‌ها را بررسی کنید.
- روی دستگاه مورد اعتماد دوم، بازیابی Backup و ورود را قبل از سفر آزمایش کنید.
- GitHub عمومی محل نگهداری Private Key، حتی نسخه رمزگذاری‌شده آن، نیست.

## در سفر
با موبایل شخصی و Termius متصل شوید. اگر کامپیوتر مورد اعتماد دیگری در دسترس است، همان فایل‌ها را بازیابی و طبق WINDOWS-SETUP.md کلید را در Agent بارگذاری کنید. روی کامپیوتر عمومی یا ناشناس کلید و Passphrase را وارد نکنید؛ حتی حذف فایل بعد از استفاده خطر بدافزار را برطرف نمی‌کند.

## اگر کلید گم شد یا افشا شد
Public Key و Fingerprint برای بازسازی Private Key کافی نیستند. اگر Backup ندارید، با Console ارائه‌دهنده یا دسترسی مدیریتی باقی‌مانده کلید جایگزین ثبت کنید. در صورت افشا، کلید مشترک را در همه سرورها و همه حساب‌های ارائه‌دهنده Rotate کنید. پیش از حذف کلید قبلی، ورود با کلید جایگزین را تست کنید. حذف کلید از پنل لزوماً آن را از VPSهای موجود حذف نمی‌کند؛ authorized_keys هر مقصد نیز باید بررسی شود. Tunnelهای فعال را در این فرآیند جداگانه و با احتیاط مدیریت کنید.
