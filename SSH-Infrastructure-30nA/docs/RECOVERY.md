# بازیابی در سفر

دستورات کامل و به‌روز در [راهنمای اصلی](../README.md) بخش‌های ۱ تا ۳ هستند؛ از نسخه قدیمی اسکریپت استفاده نکنید.

ZIP در پوشه فعلی، Home یا Downloads به‌صورت خودکار پیشنهاد می‌شود. مسیر و رمز دو ورودی متفاوت هستند. نسخه v2 از 7-Zip بدون گزینه -p خالی برای درخواست رمز هنگام استخراج استفاده می‌کند. فقط دستگاه مورد اعتماد؛ رمز چهاررقمی مناسب نیست. نسخه پشتیبان را قبل از سفر تست کنید. هیچ کلید خصوصی یا ZIP در GitHub قرار ندهید.

در صورت افشای Private Key، کلید را در تمام سرورها و پنل‌ها Rotate کنید و قبل از حذف کلید قبلی دسترسی جایگزین را تست کنید. سرورهای ایران و Tunnelهای موجود در این مرحله تغییر نمی‌کنند.
